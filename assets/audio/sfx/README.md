# assets/audio/sfx/

Simpan sound effect di sini — format `.ogg` (direkomendasikan untuk Flame).

## File yang mungkin dibutuhkan
| File | Keterangan |
|---|---|
| `jump.ogg`         | Suara loncat |
| `land.ogg`         | Suara mendarat |
| `lever_click.ogg`  | Suara tuas diklik |
| `gate_open.ogg`    | Suara gerbang terbuka |
| `fountain_on.ogg`  | Suara air mancur aktif |
| `level_complete.ogg` | Suara level selesai |

## Sumber aset gratis
- https://freesound.org (CC0 banyak tersedia)
- https://kenney.nl/assets/category:Audio (pack sfx platformer CC0)

## Catatan
Audio tidak wajib untuk MVP (PRD §8: "Audio: Opsional").
Untuk mengintegrasikan, gunakan package `flame_audio` dan tambahkan ke `pubspec.yaml`.
