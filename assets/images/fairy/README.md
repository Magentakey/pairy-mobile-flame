# assets/images/fairy/

Simpan sprite peri (fairy) di sini — satu set per warna (biru, merah, hijau, kuning).

## Rekomendasi aset
1. **Elthen's 2D Pixel Art Fairy Sprites** — https://elthen.itch.io/2d-pixel-art-fairy-sprites
   - Ukuran: 32 × 32 px, animasi: idle, fly, hurt
   - Harga: ~$1

2. **Pop Shop Packs — Fairies 2D Pixel Art** — cari di https://itch.io/game-assets/tag-fairy
   - 50+ karakter peri terbang, beberapa gratis

## File yang dibutuhkan (MVP)
| File | Keterangan |
|---|---|
| `fairy_blue.png`   | Sprite peri biru |
| `fairy_red.png`    | Sprite peri merah |
| `fairy_green.png`  | Sprite peri hijau |
| `fairy_yellow.png` | Sprite peri kuning |

Untuk MVP, warna solid berbentuk lingkaran (sudah ada di `FairyComponent.render()`) sudah cukup.
