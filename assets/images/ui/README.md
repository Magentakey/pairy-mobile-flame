# assets/images/ui/

Simpan aset antarmuka di sini: ikon tombol, panel, bingkai layar, dsb.

## Rekomendasi aset
**Kenney UI Pack** — https://kenney.nl/assets/ui-pack
- Lisensi: CC0 (bebas dipakai)
- Harga: gratis
- Berisi: tombol bulat, panel, ikon navigasi — cocok dengan gaya wireframe Pairy

## Catatan
Untuk MVP, tombol sudah dibuat secara programatik dengan `PairyButton` (Flutter widget).
Aset UI di folder ini bisa digunakan saat ingin mengganti tombol dengan sprite bergambar.
